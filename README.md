# 🌻 ช่อดอกทานตะวัน 3D หมุนได้ สำหรับหวานใจ (Sunflower Bouquet 3D Web App)

เว็บแอปพลิเคชัน 3D ช่อดอกทานตะวันสุดโรแมนติก ออกแบบตามแบบภาพเรฟเฟอเรนซ์ พร้อมกระดาษห่อสีชมพูพาสเทลลายหน้ายิ้ม ดอกคาโมมายล์ ดอกบอลเหลือง และใบยูคาลิปตัส สามารถหมุนชมได้ 360 องศา พร้อมฟังก์ชันน่ารักๆ มากมายสำหรับมอบให้คนพิเศษ ❤️

---

## 🌟 ฟังก์ชันและจุดเด่น (Features)

1. **หมุนชมได้ 360 องศา (Interactive 3D)**
   - ใช้เมาส์คลิกลาก หรือใช้นิ้วเลื่อนบนหน้าจอมือถือเพื่อหมุนชมช่อดอกไม้ได้รอบทิศ
   - ซูมเข้า-ออกเพื่อดูดีเทลกลีบดอก เกสรแบบก้นหอย Fibonacci และกระดาษห่อ
   - มีปุ่มเปิด/ปิดการหมุนอัตโนมัติ (Auto Rotate)

2. **ดีไซน์ถอดแบบจากรูปภาพจริง (Faithful to Reference)**
   - **ดอกทานตะวันสีเหลืองทอง 5 ดอกหลัก**: จัดทรงพุ่มโค้งมนสวยงาม เกสรสีน้ำตาลเข้มลวดลายธรรมชาติ
   - **ดอกคัตเตอร์/คาโมมายล์สีขาว (Chamomile)**: แซมรอบๆ ช่อเพิ่มความละมุน
   - **ดอกบอลกลมสีเหลือง (Craspedia / Billy Balls)**: แต่งแต้มสีสันสดใส
   - **ใบยูคาลิปตัส (Eucalyptus)**: ใบกลมสีเขียวเซจหม่น แซมตามขอบช่ออย่างเป็นธรรมชาติ
   - **กระดาษห่อสีชมพูพาสเทล (Pastel Pink Wrap)**: ซ้อนเลเยอร์จับจีบสวยงาม พร้อมลายหน้ายิ้มสีเหลืองสดใส
   - **โบว์ริบบิ้นสีขาว (Satin Ribbon Bow)**: ผูกที่คอดอกไม้อย่างประณีต

3. **ไฟประดับช่อดอกไม้ (Twinkling Fairy Lights ✨)**
   - มีไฟประดับเม็ดเล็กๆ ร้อยเรียงรอบช่อดอกไม้ กระพริบวิบวับอย่างอบอุ่น สามารถกดเปิด/ปิดได้

4. **เสียงเพลงกล่องดนตรี (Romantic Music Box 🎵)**
   - สังเคราะห์เสียงกล่องดนตรีกังวานหวานซึ้งด้วย Web Audio API โดยไม่ต้องโหลดไฟล์เสียงภายนอก

5. **การ์ดข้อความหวานใจ "รักเท่าไปกลับดวงจันทร์" (Love Card 💌🌙)**
   - เมื่อคลิกหรือแตะที่ช่อดอกไม้ จะปรากฏการ์ดข้อความหวานใจพร้อมคำว่า **"🌙 รักเท่าไปกลับดวงจันทร์ ✨"** (I love you to the moon and back)
   - หน้าต่างการ์ดจดหมายรัก ออกแบบพร้อมไอคอนพระจันทร์สีทอง สามารถคลิกแก้ไขข้อความ พิมพ์ชื่อหวานใจ และกดคัดลอกได้ทันที

6. **คลิกที่ช่อดอกไม้เพื่อเปิดการ์ด & ส่งความรัก (Interactive Bloom 💕)**
   - เมื่อคลิกหรือแตะที่ช่อดอกไม้ ดอกทานตะวันจะเด้งบานอย่างนุ่มนวล พร้อมเสียงฮาร์ปใสๆ และมีละอองหัวใจพวยพุ่ง ก่อนเปิดการ์ดแสดงความในใจขึ้นมาให้อัตโนมัติ

7. **ถ่ายภาพความละเอียดสูง (Snapshot Camera 📸)**
   - กดปุ่มกล้องถ่ายรูปเพื่อเซฟภาพมุมที่ชอบเป็นไฟล์รูปภาพ PNG สำหรับตั้งเป็นวอลเปเปอร์หรือส่งให้หวานใจ

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดดูบนเครื่องคอมพิวเตอร์ของคุณ
- ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดบนบราวเซอร์ (Google Chrome, Microsoft Edge, Safari ฯลฯ) ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

### 2. วิธีส่งให้หวานใจเปิดดูบนมือถือหรือคอมพิวเตอร์
- **วิธีที่ 1 (ง่ายที่สุด):** ส่งไฟล์ `index.html` ให้หวานใจผ่าน LINE / Telegram / Google Drive แล้วเปิดด้วยบราวเซอร์
- **วิธีที่ 2 (ทำเป็นลิงก์ออนไลน์ สวยงามระดับมืออาชีพ):**
  - นำไฟล์ `index.html` ไปอัปโหลดบนเว็บฟรี เช่น:
    - [Netlify Drop](https://app.netlify.com/drop) (เพียงลากโฟลเดอร์นี้ไปวาง ก็จะได้ลิงก์เว็บ `https://....netlify.app` ส่งให้หวานใจทันทีใน 30 วินาที!)
    - [Vercel](https://vercel.com)
    - [GitHub Pages](https://pages.github.com)

## 🎨 การปรับแต่งเพิ่มเติม (Customization)
- หากต้องการเปลี่ยนข้อความเริ่มต้นในการ์ด สามารถเปิดไฟล์ `index.html` ในโปรแกรม Text Editor หรือ Notepad แล้วค้นหาคำว่า `เธอคือรอยยิ้มและความสดใส` เพื่อแก้ไขเป็นข้อความที่คุณต้องการได้เลยครับ
